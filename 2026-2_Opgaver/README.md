#### Point Size

* point size kan sættes per sketch i:
  * Model -> View -> Object style -> Point size: 
    * default: 2
    * prøv: 10
* point size kan sættes for alle nye sketch i:
  * Edit -> Preferences -> Part/Part Design -> Shape Appearance
    * Vertex size: Default 2
